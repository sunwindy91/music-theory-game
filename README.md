# 乐理小达人

面向音乐初学者的浏览器端乐理练习小游戏，无需安装，打开即玩。

## 本地运行

```bash
python -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

## 功能

- **综合练习** — 音名、音程、节奏、调号、和弦等 30 道选择题
- **听音识名** — Web Audio 合成音高，三档难度
- **符号翻翻乐** — 乐理符号配对记忆
- **演奏练习** — 钢琴 / 吉他 / 架子鼓键盘演奏
- **灵气星图** — 沉浸式聆听小游戏
- **错题本** — 间隔复习（SRS），巩固薄弱题
- **每日挑战** — 每天 10 题打卡，连续 streak
- **分享卡片** — 练习完成后生成 PNG 分享图

## 开发工具（默认关闭）

| 工具 | 启用方式 |
|------|----------|
| UX 模拟测评 | `?sim=1` 或 `AppFeatures.uxSimulator = true` |
| 人设模拟 | `?persona=1` 或 `AppFeatures.personaSimulator = true` |

人设模拟支持三种用户类型（小白 / 乐感型 / 乐理大师），可预估错题本增长与薄弱题型。

## 部署

### Vercel

项目已含 `vercel.json`，使用个人 `VERCEL_TOKEN` 自行部署即可。

### Gitee Pages

1. 在 Gitee 创建仓库，推送本项目代码
2. 仓库 → **服务** → **Gitee Pages** → 启用
3. 部署分支选 `master`（或 `main`），目录选 `/`（根目录）
4. 保存后获得 `https://<用户名>.gitee.io/<仓库名>/` 访问地址
5. 每次 push 后需在 Pages 设置中手动「更新」或开启自动更新

> 纯静态站点，无需构建步骤。确保 `index.html` 在仓库根目录。
