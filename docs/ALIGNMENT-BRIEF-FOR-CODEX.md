## 5. 约束与铁律（摘 Skill · 短）

1. **无构建链**；视觉保持 Fredoka **紫橙**；新玩法走 `AppShell` + 模块挂载  
2. **Git**：勿擅自 commit/push/deploy；用户点名才可（本仓库当前 `master` = Gitee）  
3. **玩家文案禁止外部作品名**（机制可写 REFERENCE，UI 用自家词）  
4. **双端 UX**：PC 点/拖 + 手机点/滑；Pointer Events；弦乐可扫弦  
5. **星图 = 全屏可玩世界**，不是卡片死 demo；改动优先 `modules/spirit-journey/`  
6. **远征 ≠ Roguelike 清档**（I66）；清场勿静默踢回星图  
7. **面板守卫**：新模态必须进 `forceCloseAllPanels` + `update()` + 波次推进两处守卫  
8. **大功能**：短计划→确认→小步；新想法先 IDEA，再排期  
9. **开源 GitHub**：必须用户说「开源到 GitHub」才建 remote / 公开仓
