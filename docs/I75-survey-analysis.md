## 修复：三屏 Onboarding

学路径第一课之前，轻量轮播卡：

- 屏一：五线谱是什么 + 线和间示意图占位 + 继续
- 屏二：这一课你会学到什么 + 继续
- 屏三：学完你能做什么 + 开始第一课

localStorage `onboarding_done`。老用户不弹。右上角跳过按钮。

不改星图。不改 PC 键鼠。
