## 2. GitHub 开源 / 社区共维护

**现状**：Gitee 备份 + Cloudflare 国内站可分享试玩。

**开源检查清单（你下令「开源到 GitHub」时再执行）**

- [ ] 选 LICENSE（建议 MIT，与静态前端常见做法一致）  
- [ ] README：一句话、截图、本地启动、`?dev=1`、贡献方式  
- [ ] `CONTRIBUTING.md`：小 PR、先 Issue、不擅自大改玩法  
- [ ] `.gitignore` 确认无密钥 / `.wrangler` 敏感缓存策略  
- [ ] `git remote` 增加 GitHub；首次 push 由你确认  
- [ ] Issues 模板：Bug / 想法（链到 IDEA-BACKLOG 标签）

**分享话术**：试玩链 + GitHub 星标/Issue，比只丢网盘清晰。
