# UX 原则 · 「用户很懒」与渐进披露

> **来源**：2026-07-25 首轮问卷/体感反馈（UI/UX）  
> **用途**：壳层与星图交互改版的产品约束；对齐多邻国式「一次只看一件事」  
> **关联**：`IDEA-BACKLOG` I69–I71 · Skill 双端 UX · `SHARE-SCRIPT`（试玩仍可用 `?dev=1`）

---

## 1. 核心假设：用户很懒（不是贬义）

| 假设 | 产品含义 |
|------|----------|
| 不愿意扫一屏「很多课」 | 正式版首页**不要**默认展开完整学习路径地图 |
| 惯性找「现在该点哪」 | 首屏只给 **1 个主行动**（继续本节 / 今日复习 / 去玩） |
| 细节越多越焦虑 | 关卡细则、支线、芯片墙 → **完成后再露**或藏进「更多」 |
| 手机没有物理方向键 | 触控必须有**左手轮盘 + 右手开火/切弹**，不能假设会「想得到点画面」 |

设计检验：**拿掉导航文案后，陌生人 3 秒内能否知道下一步点哪里？** 不能 → 未过关。

---

## 2. 正式版信息架构（目标态）

```
首页大类（对等入口，类似现双核）
├── 学   → 只见「当前一课 / 继续」；通关后才见下一关（多邻国式）
├── 玩   → 星图（练习房/远征）；手机强制横屏战斗壳
└── 复习 → 错题本 / 每日待复习（从 setup 小字升级为大类）
```

- **`?dev=1` / 测试**：可保留全路径展开，方便联调与问卷深测。  
- **正式（无 dev）**：路径用「焦点卡」；全图进「路线图 / 已学」二级页。  
- **练习中心芯片墙**：勿与「学」的焦点卡抢首屏；可挂在学完后的「练一练」或复习侧。

---

## 3. 关卡细节何时展示？

**同意「刚进去就明晃晃铺满细节不好」。**

| 时机 | 可见 |
|------|------|
| 未开始 / 刚进学 | 本节标题 + 一句目标 + 主按钮「开始」 |
| 进入本节后 | 逐步揭露（课内步骤） |
| 通关结算 | 下一关预告一句；可选「查看路线图」 |
| 已通节点 | 可回看详情；默认折叠 |

星图战役星门可保留图标级信息，但**首进远征**仍应用 tip/引导，而非说明书墙。

## 4. 手机星图 · 王者式操控（目标态）

| 端 | 移动 | 开火 / 切弹 / 闪避 |
|----|------|-------------------|
| PC | WASD / 方向键 | 空格开火 · 1–4/R 切弹 · Shift 闪 · E 撞击 |
| 手机 | **强制横屏** + **左虚拟摇杆** | **右：开火（大）/ 闪避 / 撞击（小）**；**切弹顶栏**；对齐现有键位语义 |

原则：

1. **同一套游戏逻辑**，两套输入适配层（`InputAdapter`: keyboard | touchMOBA）。  
2. 竖屏进星图 → 提示旋转或自动 `orientation` lock（能力允许时）。  
3. 摇杆只产生方向向量，映射现有 `vx/vy`；松手归零。  
4. 右手钮不要挡住 Boss telegraph 中央视野；可半透明。  
5. 与「点画面开火」并存时：MOBA 布局下以右钮为主，避免误触冲突。

对标：王者荣耀（左移右技），**不是**照搬技能树，只借操作分区。

## 5. 分期落地（建议顺序）

| 刀 | 内容 | 难度 | 建议所有者 |
|----|------|------|------------|
| A | 首页「学 ‖ 玩 ‖ 复习」三门 + 正式版隐藏全路径，只留焦点卡 | 中 | **已落地·v1.7.21** |
| B | 学路径渐进披露（多邻国式下一关） | 中 | **已落地·v1.7.21**（焦点卡 + 展开全图） |
| C | 手机星图：横屏 + 左摇杆 + 右开火簇（InputAdapter） | 大 | **MVP1+2+撞击·v1.7.26**（Codex 三调已收；撞击 36px 接 tryRam） |
| D | 战役/关卡详情默认折叠 | 小 | Cursor |

**不要一次做完。** 问卷反馈优先落 A→C（手机玩不动会直接杀死「玩」核）。

## 6. 何时叫 Codex

| 需要 | 叫 Codex |
|------|----------|
| 三门信息架构文案 / 竞品对标一段 | 可选 |
| 摇杆+横屏的边界情况清单（iOS Safari / 安卓） | **建议**出一页审阅，再由 Cursor 实现 |
| 直接改 `spirit-journey.html` | 不必；Cursor 领地更熟 |

口令示例：「按 UX-LAZY-USER 审 C 刀操控方案，只出分区与风险，不写代码」。
