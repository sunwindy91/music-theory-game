> **版本锚点**：代码至 **v1.7.15**（检查点含 v1.7.14）；试玩 https://music-theory-game-br5.pages.dev/

---

## Situation

乐理入门常停在「刷对选项」：会选，却说不清构成；若只做题库 App 又缺少持续动机。目标用户是零基础到初学，需要**学得懂**也要**愿意回来玩**。

## Task

在**无构建链、静态可部署**约束下，3 周量级迭代出可分享的双核产品：学习路径（LessonEngine / 识谱）+ 全屏可玩星图（战役节点 / Boss / 养成），并能用反馈闭环证明「发现问题 → 改版」。

## Action

1. **产品取舍**：明确「两个游戏一个壳」是有意双核，用分期切片避免一次做完两款完整游戏。  
2. **教学玩法化**：捡音凑大三/小三装弹、抗性怪、关卡教案条；错题与 why 文案贯通。  
3. **世界可玩**：战役星图（非自动刷图）、远征局跨节点保留养成（I66）、Boss telegraph / 分阶段技能。  
4. **协作系统**：Skill + HANDOFF 断点 + IDEA 积压 = Agent 飞轮，支撑连续交付与弱模型续航。  
5. **验证入口**：静态问卷页（5 题）+ 页脚 CTA，先收 8–15 人质性反馈再排下一刀。

## 面试追问预备

- **为什么双核不拆成两个产品？** 同一灵气进度贯通动机；壳层分期挂模块。  
- **最大失败？** 曾静默踢出远征 / 闪步像掉帧 → 记入审校表后改 I66 与 telegraph。  
- **下一步？** 问卷归集 → 按「最想改」排序；GitHub 开源（LICENSE/CONTRIBUTING 已备）。
